# Predicción de Pasajeros de Aerolínea

Proyecto de regresión / series de tiempo listo para Google Colab. Incluye EDA, lags, modelos y SHAP.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/pasajeros-aerolinea/blob/main/pasajeros_aerolinea_colab.ipynb)

## Contenido

- Serie de pasajeros mensuales simulada (tendencia + estacionalidad + ruido)
- Features: lags, media móvil, feriado, precio de combustible
- EDA (plot de serie, boxplot, scatter)
- Modelos: Ridge, Random Forest, Gradient Boosting
- Feature importance
- **SHAP** (summary plot)
- Conclusiones

Datos: simulados

Rango esperado (ejemplo): R² > 0.80
